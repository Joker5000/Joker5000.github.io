# Telegram AI Moderator

Русскоязычный Telegram-бот для модерации группы с закрытой панелью управления для владельца и доверенных администраторов.

## Что уже есть

- Русский интерфейс.
- Закрытое меню `/admin`: доступ проверяется по Telegram ID на сервере.
- Владелец может добавлять/удалять администраторов командами `/addadmin ID` и `/deladmin ID`.
- PostgreSQL для администраторов, правил, предупреждений и инцидентов.
- Redis подготовлен для flood/rate-limit/кэша.
- Режим ASSIST: серьёзные санкции предполагают подтверждение администратора.
- Кнопки предупреждения, мута 24ч, бана и пропуска инцидента.
- Docker Compose и автоматическая установка на Ubuntu/Debian.
- Секреты хранятся только в `/opt/tg-ai-moderator/.env` на VM.

## Установка

На чистой Ubuntu/Debian VM:

```bash
curl -fsSL https://raw.githubusercontent.com/Joker5000/Joker5000.github.io/telegram-ai-moderator/telegram-ai-moderator/install.sh | sudo bash
```

Установщик спросит Bot Token и Telegram ID владельца. Токен не записывается в GitHub.

После установки:

```bash
moderator status
moderator logs
```

Затем добавьте бота в группу и выдайте права администратора: удаление сообщений, ограничение участников и бан.

## Админ-панель

Напишите боту в личные сообщения:

```
/start
/admin
```

Обычный пользователь получает только сообщение об отсутствии доступа. Все callback-кнопки повторно проверяют Telegram ID, поэтому пересылка/подделка callback не даёт административных прав.

## Важно

Anti-alt является вероятностной системой: Telegram Bot API не предоставляет боту IP-адрес, device ID или номер телефона участника. Такие сигналы нельзя использовать как достоверный fingerprint.
