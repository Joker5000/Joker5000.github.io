# Аватары персонажа

Веб-интерфейс использует `assets/moderator-logo.svg` как основную иконку.

Для самого Telegram-бота предусмотрены два уровня:

1. Имя/описание — меняются через Bot API.
2. Фото/видео профиля — Telegram это поддерживает через MTProto API, поэтому для автоматической смены аватарки нужен отдельный MTProto worker (например Telethon) с API_ID/API_HASH владельца бота.

По умолчанию автосмена аватарки выключена. Это безопаснее и не требует пользовательской Telegram-сессии на сервере.
