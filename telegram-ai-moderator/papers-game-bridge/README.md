# Papers, Please — Telegram Moderator Bridge

Экспериментальный BepInEx-мод для **легальной установленной копии Papers, Please (Unity/IL2CPP)**.

Он превращает реальную игру в дополнительный интерфейс рассмотрения Telegram AI-инцидентов:

- VM хранит очередь AI-инцидентов.
- Мод получает следующий инцидент через `/api/game/next`.
- Реальный путешественник игры получает имя Telegram-пользователя.
- Настоящий игровой штамп APPROVED -> помиловать.
- Настоящий игровой штамп DENIED -> предупреждение.
- Следующий этап: detain -> Telegram mute, rifle/shot -> Telegram ban.
- Следующий этап: отдельные игровые papers для истории сообщений и AI-жалоб.
- Следующий этап: профильная фотография Telegram в кастомном документе.

## Почему этот путь лучше HTML-копии

Штамповочный механизм, анимации, физика документов, стол, booth и остальные детали рендерит сама игра. Поэтому визуальная часть совпадает с установленной версией игры без повторной реализации интерфейса в браузере.

## VM

Нужны публичный HTTPS URL (или Tailscale/WireGuard) и `GAME_BRIDGE_TOKEN`.

`GAME_BRIDGE_TOKEN` лежит в:

`/opt/tg-ai-moderator/.env`

## Важно

Репозиторий LittleBigBug/papers использован как технический референс для точек интеграции с Unity/IL2CPP. В просмотренной версии репозитория отдельный LICENSE-файл не обнаружен, поэтому его исходники и игровые ассеты не копируются сюда; bridge реализуется отдельно.
